
# My First Streamlit App

## About Project

This is my first Streamlit application created using Python.

The app allows users to select a number using a slider and displays the square of the selected number.

## Technologies Used

- Python
- Streamlit

## Features

- Display a title
- Display text
- Interactive number slider
- Calculate the square of a number

## How to Run

Install Streamlit:

```bash
pip install streamlit
```

Run the application:

```bash
streamlit run app.py
```

## Example

If you select the number 5:

Output:

The square of 5 is 25.
